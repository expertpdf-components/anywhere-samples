Rendering engines

The converter loads the HTML in a rendering engine and turns the rendered page into PDF. The engine is chosen with the RenderingEngine property.

EngineBest forNotes
ChromiumModern pages: HTML5, CSS3, flexbox and grid, web fonts, JavaScript frameworks Recommended. Runs out of process; produces tagged (accessible) PDF and PDF/A-3a.
BlinkModern pages, .NET Core and .NET Framework 4.6.1+ applications Available through the NetCore packages.
WebKitSimple, static pages; the smallest deployment Built in: no extra files besides the engine library next to the DLL.

Accessible PDF, PDF/A and electronic invoices

A tagged PDF keeps the logical structure of the page (headings, paragraphs, lists, tables, figures with their alternate text and the reading order), so screen readers and other assistive technologies can use it. Set Tagged = true and the document Language, and use the Chromium or Blink engine.

PDF/A documents are made for long-term archiving: fonts are embedded and the document is self-contained. PDF/A-3 can also carry associated files, which is how ZUGFeRD and Factur-X electronic invoices embed their machine-readable XML next to the visible invoice.
