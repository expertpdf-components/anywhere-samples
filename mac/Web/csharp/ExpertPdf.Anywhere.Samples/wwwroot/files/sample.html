Accessible PDF, PDF/A and electronic invoices

A tagged PDF keeps the logical structure of the page (headings, paragraphs, lists, tables, figures with their alternate text and the reading order), so screen readers and other assistive technologies can use it. Set Tagged = true and the document Language.

PDF/A documents are made for long-term archiving: fonts are embedded and the document is self-contained. PDF/A-3 can also carry associated files, which is how ZUGFeRD and Factur-X electronic invoices embed their machine-readable XML next to the visible invoice.

Page layout

This heading starts a new PDF page because of the CSS page-break-before: always style. The converter also honors page-break-after and page-break-inside: avoid, and it keeps lines of text and images from being cut between pages.
